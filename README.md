**# Mundiales Fútbol Historia — V2

Sitio web estático para consultar la historia de los Mundiales de fútbol.

## Contenido
- Mundiales 1930–2026
- Línea histórica
- Filtro por año
- Estadios
- 10 jugadores destacados
- Balones y materiales
- Curiosidades
- Búsqueda
- Mapa de sedes
- Formulario de colaboración

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio.
3. Asegúrate de que `index.html` quede en la raíz.
4. Ve a **Settings → Pages**.
5. En **Build and deployment → Source**, selecciona **GitHub Actions**.
6. Haz un push a la rama `main` o ejecuta el workflow desde **Actions**.
7. GitHub mostrará el enlace publicado en la configuración de Pages.

## Publicar en Vercel

1. Crea un repositorio en GitHub y sube estos archivos.
2. En Vercel, importa ese repositorio.
3. Como es una web estática, no necesitas un framework ni un comando de build.
4. Deja el directorio raíz como directorio del proyecto.
5. Pulsa Deploy.
6. Vercel generará una URL pública para compartir.

## Importante

El formulario de colaboración de esta versión guarda los aportes en el navegador mediante `localStorage`; no existe todavía una base de datos ni un servidor backend.
